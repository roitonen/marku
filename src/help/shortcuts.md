# Keyboard Shortcuts

On Windows/Linux use `Ctrl` where `Cmd` is shown.

## Files and tabs

| Action | Shortcut |
| --- | --- |
| New tab | `Cmd+T` |
| Open file | `Cmd+O` |
| Open recent | `Cmd+Shift+O` |
| Save | `Cmd+S` |
| Save As | `Cmd+Shift+S` |
| Print / export PDF | `Cmd+P` |
| Close tab | `Cmd+W` |
| Previous / next tab | `Cmd+[` / `Cmd+]` |
| Go to tab 1...9 | `Cmd+1` ... `Cmd+9` |
| Hide / show tab bar | `Cmd+Shift+T` |
| Settings | `Cmd+,` |

## Editing

| Action | Shortcut |
| --- | --- |
| Undo / redo | `Cmd+Z` / `Cmd+Shift+Z` |
| Bold | `Cmd+B` |
| Italic | `Cmd+I` |
| Strikethrough | `Cmd+Shift+X` |
| Display math | `Cmd+Shift+M` |
| Link | `Cmd+K` |

## View

| Action | Shortcut |
| --- | --- |
| Toggle Source View | `Cmd+E` |
| Find (in Source View) | `Cmd+F` |
| Render preview | `Cmd+R` |
| Increase / decrease font | `Cmd+=` / `Cmd+-` |
| Reset font size | `Cmd+0` |
| Word wrap | `Cmd+.` |

## Help

| Action | Shortcut |
| --- | --- |
| Marku Help | `F1` or `Cmd+Shift+H` |
| Keyboard Shortcuts | `Cmd+Shift+K` |
